A dark lord with a functioning apocalypse and a dwindling supply of patience briefs his put-upon minion on the evening's schedule: black candles, one gate, one eclipse, one hero, a filing problem even he cannot conquer, and the same speech he has given four times before.

## Run it

```sh
node main.ts
```
